# Activity Creator Permissions — Odoo 19

## الإصدار 19.0.1.0.1
- منشئ النشاط أو مدير النظام يستطيع إدارة النشاط وإلغاءه.
- المستخدم المسند إليه يستطيع إكمال النشاط المسند إليه هو فقط.
- لا يستطيع المستخدم الضغط على Done لإكمال نشاط مسند إلى مستخدم آخر.
- فحص الصلاحيات مطبق على الخادم أيضًا، وليس على إظهار الأزرار فقط.

## التحديث على Odoo.sh
1. استبدل مجلد `activity_creator_permissions` القديم بهذا المجلد.
2. نفّذ commit ثم push إلى الفرع المطلوب.
3. انتظر اكتمال البناء.
4. من Apps حدّث قائمة التطبيقات، ثم افتح الموديول واضغط Upgrade.
5. اختبر على قاعدة تجريبية قبل الإنتاج.

## ملاحظات
- يعتمد على `mail` ويستهدف Odoo 19.
- المنشئ هو المستخدم الموجود في `Created by` (create_uid).
- علامة Done تعني إكمال النشاط وليست موافقة/رفضًا رسميًا.
- تم التحقق من صياغة ملفات Python فقط؛ يلزم اختبار التوافق داخل نسخة Odoo 19 الفعلية.
