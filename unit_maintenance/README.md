# صيانة الوحدات (unit_maintenance) – Odoo 19

## التثبيت
1. ضع المجلد `unit_maintenance` داخل مسار addons ثم: Apps ← Update Apps List ← ثبّت «صيانة الوحدات».
2. يعتمد على: `mail`, `product`, `account`, `stock`, `sms`. يلزم `wkhtmltopdf` لتقرير PDF.
3. لإرسال OTP عبر Taqnyat، أضف معاملات النظام التالية من الإعدادات التقنية ← المعاملات ← معاملات النظام:
   * `unit_maintenance.sms_provider` = `taqnyat`
   * `unit_maintenance.taqnyat_api_token` = Bearer Token (يُحفظ سرياً في الخادم ولا يوضع في ملفات الموديول)
   * `unit_maintenance.taqnyat_sender` = اسم مرسل SMS المعتمد في حساب تقنيات
   * `unit_maintenance.otp_test_mode` = `0` للإرسال الفعلي، أو `1` للاختبار المحلي دون إرسال.
   * تأكد من تفعيل إرسال API في تقنيات وإضافة عنوان IP العام الخارج من خادم Odoo إلى القائمة المسموحة، وأن رصيد الحساب واسم المرسل صالحان.
   * يستخدم الموديول Taqnyat SMS API (`POST https://api.taqnyat.sa/v1/messages`) لإرسال رمز ينشئه Odoo ويتحقق منه محلياً. أرقام المستلمين ترسل بصيغة دولية دون علامة +.
4. المجموعات: **فني** / **موظف** / **مدير** (مدير النظام يحصل على «مدير» تلقائياً).

## تهيئة البيانات
المباني ← الوحدات (المالك = عميل Odoo، تاريخ التسليم، مدة الضمان بالأشهر، الافتراضي 24).
**يجب أن يكون جوال العميل في حقل الهاتف بكرت العميل** حتى يعمل التحقق (تُطبَّع الصيغ: 0502441702 = +966502441702).

## دورة الطلب
`جديد ← مسند لفني ← (بانتظار التسعير للخارجي) ← قيد الصيانة ← مكتمل`
* النوع يُحدد تلقائياً: داخلي إذا كانت الوحدة تحت الضمان، وإلا خارجي (قابل للتعديل). الترقيم: INT-1001 / EXT-1001 للطلبات، SHK-0001 للشكاوى.
* الفني يضيف المنتجات ← الخارجي يذهب للإدارة لتسعيره ← المدير يعتمد السعر ← الفني يأخذ توقيع العميل ← يبدأ الصيانة (المؤقت) ← الصور قبل/بعد ← التقرير ← إرسال التقرير.
* أي تعديل على المنتجات أو الأسعار بعد الاعتماد يُلغي الاعتماد والتوقيع.
* **إعادة الإرسال**: متاحة على الطلب المكتمل في أي وقت (زر في النموذج، ونقطة `send_report` في API)، ويُسجَّل كل إرسال في سجل الإرسال.
* الفاتورة: زر «إنشاء فاتورة» للصيانة الخارجية المكتملة.

## شكوى العميل (بدون تسجيل دخول)
1. `POST /unit_maintenance/api/complaint/otp/request` `{"phone": "0502441702"}`
   * الرقم غير موجود في كروت العملاء ← 404 `not_registered` (يمكن إخفاء ذلك بـ `reveal_unregistered=0`).
   * موجود ← يولّد Odoo رمزاً (4 أرقام) ويرسله SMS. لا يُخزَّن الرمز بل بصمته (HMAC).
2. `POST /unit_maintenance/api/complaint/otp/verify` `{"phone": "...", "code": "4817"}` ← `{"token": "...", "units": [{"id", "label", "building", "unit", "owner"}]}`
   * `label` جاهز للقائمة المنسدلة: «عمارة X · وحدة Y · المالك: Z».
3. `POST /unit_maintenance/api/complaint/submit` `{"phone", "token", "unit_id", "description"}` ← `{"ref": "SHK-0001"}`
   * الرمز المميز صالح 30 دقيقة ولشكوى واحدة. الوحدة يجب أن تعود لنفس الرقم.
4. تصل الشكوى للموظفين (إشعار)، ويحوّلها الموظف إلى طلب بزر «تحويل إلى طلب صيانة».

الحماية: صلاحية الرمز 5 دقائق، 5 محاولات، 3 رموز/ساعة للرقم، 10 طلبات/ساعة للـ IP، 5 شكاوى/يوم للرقم.

## API الفني
تسجيل الدخول: `POST /unit_maintenance/api/login` `{"login","password"}` ← كوكي الجلسة (يُرسل مع باقي الطلبات). كل الطلبات POST بجسم JSON:

| المسار | الجسم | الوظيفة |
|---|---|---|
| `/api/dashboard` | `type, date_from, date_to, q` | العدادات والنسب (الأزرار والفلاتر) |
| `/api/jobs` | `type: internal/external, q` | قائمة العملاء/المهام المفتوحة |
| `/api/job` | `id` | تفاصيل الطلب والخطوات (المنتجات/التسعير/التوقيع) |
| `/api/products` | `q` | كتالوج المنتجات (بدون أسعار) |
| `/api/set_products` | `id, lines:[{product_id, quantity}]` | حفظ منتجات الطلب |
| `/api/request_price` | `id` | إرسال للإدارة للتسعير (الخارجي) |
| `/api/signature` | `id, signature(base64)` أو `clear:true` | توقيع العميل |
| `/api/start` | `id` | بدء الصيانة (يبدأ المؤقت، `start` في التفاصيل) |
| `/api/photo` | `id, kind: before/after, image(base64), note` | صورة |
| `/api/finish` | `id, report` | إنهاء وتقرير الفني |
| `/api/send_report` | `id, method: wa/mail` | إرسال أو إعادة إرسال (wa يعيد رابط واتساب جاهز) |
| `/api/done` | `q, date_from, date_to` | الصيانات المكتملة (لإعادة الإرسال) |

(المسار الكامل يسبقه `/unit_maintenance`.) السعر لا يظهر للفني في الخارجي قبل اعتماد الإدارة. رابط التقرير العام للواتساب: `/unit_maintenance/report/<id>/<token>`.

## معاملات النظام (Settings ← Technical ← System Parameters)
`unit_maintenance.sms_provider`, `taqnyat_api_token`, `taqnyat_sender`, `otp_test_mode`, `default_warranty_months`, `default_country_code`, `otp_length`, `otp_ttl_minutes`, `otp_max_attempts`, `otp_max_per_hour`, `otp_max_per_ip_hour`, `reveal_unregistered`, `max_complaints_per_day`, `token_ttl_minutes`، و`otp_test_mode=1` للتطوير فقط (يكتب الرمز في سجل الخادم بدل SMS).
